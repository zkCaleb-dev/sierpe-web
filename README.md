# sierpe-web

The website for [Sierpe](https://github.com/zkCaleb-dev/sierpe), a
self-hosted Stellar indexer. Built with [Hugo](https://gohugo.io) — no
theme, hand-written layouts, no JavaScript.

## Develop

```bash
brew install hugo
hugo server
```

## Build

```bash
hugo build
```

Output lands in `public/`. Deployed on Vercel (framework preset: Hugo).
